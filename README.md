# Ecommerce Platform

Flipkart jaisa e-commerce platform - user order kar sakta hai, admin ko order ki puri jankari milti hai.

## Setup
1. `backend` folder me `npm install` chalao
2. `.env.example` ko copy karke `.env` banao aur MongoDB link + JWT secret daalo
3. `npm start` se server chalu karo

## Features
- User signup/login
- Product listing
- Order place karna
- Admin: sabhi orders dekhna (kisne kya order kiya)
- Admin: order status update (pending/shipped/delivered)
